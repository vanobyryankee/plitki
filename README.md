# Плитки

Стеклянные папки и виджеты на рабочем столе Windows в духе iOS.

*Glass folder tiles and widgets for the Windows desktop, iOS style. Available in 10 languages.*

## Что умеет

- **Папки-плитки.** Ярлыки собираются в стеклянные папки прямо на рабочем столе. Это обычные папки на диске: перетащи ярлык на плитку, и он окажется внутри.
- **Виджеты:**
  - музыка (обложка, трек, кнопки);
  - корзина;
  - часы;
  - нагрузка ПК (процессор, память, видеокарта);
  - погода с прогнозом;
  - заметка;
  - «Пульт сети» (VPN, zapret и Телеграм у одноимённого приложения).
- **Формы и размеры.** Любой виджет тянется за край и сам перестраивается: в ряд, квадратом или столбиком.
- **Стекло.** Настоящее размытие обоев, в том числе Wallpaper Engine. Оттенок, размытие, тень, кромку и скругление можно настроить.
- **Сетка.** Своя на каждом мониторе, её можно подогнать под значки рабочего стола.
- **Языки:** русский, English, 中文, Español, Português, Français, Deutsch, 日本語, 한국어, Türkçe.

## Установка

1. Скачай архив `Plitki-win-x64.zip` в разделе [Releases](../../releases).
2. Распакуй в любую папку и запусти `Tiles.exe`.

Нужна Windows 10 (19041) или 11. Запуск вместе с Windows включается в окне приложения.

## Сборка из исходников

Нужен .NET 8 SDK.

```
dotnet test tests\Tiles.Tests
dotnet publish src\Tiles.App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o out
```
