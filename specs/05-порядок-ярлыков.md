# 05. Порядок ярлыков в папке

## Решения владельца (06.11.2026, опрос)
- Где переставлять: «В открытой папке». Тянешь ярлык, соседи плавно расступаются, превью на плитке берёт первые по порядку.
- Вынос наружу: «Утащить за край папки». Внутри окна папки ярлык переставляется, за краем едет на стол или в другую папку, как раньше.
- Новые ярлыки: «В конец».
- Кнопка «по алфавиту»: «Не нужна».

## Как устроено
- У папки в настройках список имён файлов `Order`. Пустой — по алфавиту, как было.
- Показ: сначала ярлыки из списка в его порядке, потом все остальные по алфавиту (новые и переименованные встают в конец).
- Порядок — часть папки, поэтому попадает и в расстановки (пресеты).

## Приёмка (вход → результат)
1. Order пуст, файлы b, a, c → a, b, c.
2. Order [c, a], файлы a, b, c → c, a, b.
3. Order [x, a] (x удалён), файлы a, b → a, b.
4. Перенос: [a, b, c, d], с 0 на 2 → [b, c, a, d]; с 3 на 0 → [d, a, b, c].
5. Клетка под курсором: 4 колонки, 6 ярлыков, точка во 2-й строке 1-й колонке → 4; за последним → 5 (последний); выше/левее → 0.
6. В игре: тянешь ярлык внутри открытой папки — он едет за мышью, соседи плавно съезжают; отпустил — порядок сохранён, превью на плитке обновилось.
7. Вытянул за край окна папки — ярлык уезжает на стол/в другую папку как раньше.
