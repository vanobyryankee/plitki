# Плитки-папки на рабочем столе (как в iOS/Android)

Дата: 05.11.2026. Статус: ждёт «да» владельца.

## Решения владельца (опрос 05.11.2026, дословно по выбору)

- Способ: «Своя лёгкая программа» (не мод Windhawk, не Stardock Fences).
- Наполнение: «Перетаскивать мышью» — тащишь ярлык на плитку, он уходит в папку; вытаскиваешь из окошка — возвращается на стол.
- По клику: «Рядом с плиткой» — небольшая панель выезжает из плитки, остальной стол виден.
- Плитка закрытая: «Мини-значки внутри» — сетка маленьких значков на прозрачном стекле и подпись снизу.
- Размер плитки: примерно четыре ярлыка (2×2 клетки сетки рабочего стола). Стекло «как в iOS».

## Как устроено

- Программа «Плитки» (C#, WPF, .NET 8), один exe, запуск вместе с Windows (HKCU\...\Run), значок в трее.
- Плитка — своё окно без рамки, без кнопки на панели задач и в Alt+Tab, лежит под всеми окнами
  (как виджет). Стекло: системный акрил Windows 11 + скруглённые углы + тонкая светлая кромка.
- Папка = настоящая папка на диске `C:\Users\user\Desktop-Плитки\<Имя>\`. Ярлык, брошенный на
  плитку, **перемещается** туда (не копируется, не удаляется). Вытащенный из панели — перемещается
  обратно на `Desktop`. Программа никогда не удаляет файлы: «Удалить папку» возвращает всё на стол.
- Настройки (плитки, имена, позиции): `Desktop-Плитки\tiles.json`.

## Пункты и критерии приёмки (вход → ожидаемый результат)

1. Плитка 2×2 клетки с мини-значками (до 9, сетка 3×3) и подписью.
   Вход: в папке 5 ярлыков → на плитке 5 мини-значков, подпись = имя папки.
2. Перетащить ярлык со стола на плитку → файл пропал со стола, лежит в папке, мини-значок появился.
3. Клик по плитке → рядом выезжает стеклянная панель: имя папки сверху, крупные значки с подписями,
   4 в ряд. Клик по значку запускает программу и закрывает панель. Клик мимо / Esc — закрывает.
   Панель не вылезает за край экрана (открывается в ту сторону, где есть место).
4. Вытащить значок из панели на стол → файл вернулся на `Desktop`.
5. Плитку можно двигать мышью; отпускаешь — прилипает к сетке ярлыков. Позиция сохраняется
   после перезапуска.
6. Правый клик по плитке: «Переименовать», «Удалить папку (вернуть ярлыки на стол)».
   В трее: «Новая папка», «Выход», «Запускать с Windows».
7. Win+D («Показать рабочий стол») — плитки остаются видны.
8. Игры: программа ничего не внедряет в чужие процессы, в полноэкранной игре её не видно.

## Что задевает (влияние)

- Windhawk «Translucent Windows» тоже красит окна → программу «Плитки» добавить ему в исключения,
  иначе получится двойное стекло или серая заливка (как было с Aqua Voice).
- Память ~40–60 МБ, процессор в покое ~0. Хуков и внедрения нет — играм не мешает.
- Ярлыки Windows на столе могут оказаться под плиткой: плитка встаёт поверх ярлыков, сами ярлыки
  не двигаем (можно потом добавить «подвинуть ярлыки»).
- DisplayFusion (обои/мониторы) — не трогаем, плитки живут на главном мониторе.

## Проверки (до кода, должны быть красными)

Тесты xUnit на логику без окон: перемещение в папку и обратно (без потерь, с одинаковыми именами
— добавляется « (2)»), удаление папки возвращает всё; сохранение/загрузка tiles.json; прилипание к сетке;
выбор стороны открытия панели у края экрана. Интерфейс — снимком экрана после сборки.

## Надписи для пользователя

Меню и подсказки по-русски: «Новая папка», «Переименовать», «Удалить папку (ярлыки вернутся на стол)»,
«Запускать с Windows», «Выход». Новая папка по умолчанию называется «Папка».

## Доработка 06.11.2026: настройки папок, плавность, качество значков

Решения владельца (опрос 06.11.2026):
- Настройки у каждой папки свои, открываются правой кнопкой → «Настройки папки…».
- Состав: привязка к клеткам Windows (выкл — ставится куда угодно), подписи под значками на плитке,
  подписи в панели, прозрачность стекла, сила размытия, оттенок стекла, размер значков, тень,
  скругление углов, яркость кромки, показывать название папки.
- Общие настройки: «Шаблон + Применить ко всем» — шаблон даётся новым папкам, кнопка копирует его во все.
  Открываются из значка в трее → «Общие настройки…».
- Перетаскивание плитки плавное, без рывков.
- Значки без рваных краёв и тёмной каймы, как на рабочем столе.

Критерии приёмки:
- Прозрачность 18% белого → заливка #2EFFFFFF (как сейчас); значения вне диапазона обрезаются.
- Без привязки плитка встаёт ровно туда, где отпустили, но не вылезает за экран.
- Настройки одной папки не меняют другие; «Применить ко всем» меняет все; переживают перезапуск.
- Значок запрашивается в точном размере экрана (48 × 150% = 72 px), без растяжения.

## Доработка 06.11.2026 (2): скорость панели, меню Windows, запуск с плитки

Слова владельца: «когда открываешь плитку, она подлагивает, особенно когда много открыть»; «у ярлыков должно
открываться классическое контекстное меню Windows» (настройкой); «чтобы ярлыки можно было кликать, не открывая
папку… настройку в свёрнутом состоянии».

- Стекло считается из уменьшенного снимка рабочего стола (1/4), снимок обновляется раз в минуту и при сдвиге плиток,
  а не при каждом открытии; без принудительной уборки памяти на открытии.
  Приёмка: открытие панели не снимает рабочий стол заново (журнал: «glass capture» не чаще раза в минуту).
- Настройка «Меню Windows на значках» (вкл по умолчанию): правая кнопка по значку на плитке и в панели — меню
  проводника для этого ярлыка; по пустому месту плитки — меню плиток.
- Настройка «Клик по значку запускает программу» (выкл по умолчанию): клик по значку на плитке запускает его,
  клик по пустому месту, названию или «+N» открывает панель.

## Доработка 06.11.2026 (3): виджет музыки и плитка-корзина

Слова владельца: «виджет для музыки, что когда у меня играет музыка, работал бы виджет в левом нижнем углу и значок
корзины… чтобы выглядел в тему, свои кастомные значки».

Решения владельца (опрос 06.11.2026):
- Музыка: обложка, название и исполнитель, кнопки назад / пауза / вперёд, полоска прогресса.
- На паузе виджет виден с кнопкой «играть»; плеера нет — виджет плавно исчезает.
- Корзина: своя стеклянная плитка, пустая и полная отличаются; клик открывает, файлы на неё бросать,
  правой кнопкой «Очистить корзину». Обычную корзину Windows со стола убрать (вернуть, если плитку выключить).
- Свои нарисованные значки: корзина и кнопки музыки, тонкие белые линии под стекло.

Как сделано:
- Музыку берём у Windows (то же, что показывает всплывашка громкости): работает с любым плеером.
- Вид (оттенок, прозрачность, кромка, скругление, тень, размытие) — из общих настроек.
- Оба окна на рабочем столе, как плитки: не мешают окнам, ярлыки Windows из-под них уводятся.
- В трее: «Виджет музыки», «Корзина-плитка» (галочки).
- Прогресс обновляется раз в секунду, только пока музыка играет и виджет виден.

Критерии приёмки:
- Играет → виден; пауза → виден, кнопка «играть»; нет плеера → скрыт.
- Время: 65 с → «1:05», 3725 с → «1:02:05»; прогресс 30 из 120 с → 0.25, за пределами обрезается в 0..1.
- Позиция при игре: последняя позиция + прошедшее время, не дальше длины трека.
- Подпись корзины: 0 → «Пусто»; 1 → «1 файл»; 3 → «3 файла»; 5 → «5 файлов»; 11 → «11 файлов»; 21 → «21 файл».
- Виджет в левом нижнем углу рабочей области с отступом.
- Новые настройки переживают перезапуск; старый tiles.json без них читается (виджет и корзина включены).

## Доработка 06.11.2026 (4): виджеты как плитки, выделение рамкой, окно приложения с мастерской

Слова владельца: «виджет я должен мочь двигать, такой же системой, как папка»; «не отрисовывает обложку»;
«выглядит не стилизованно, слишком тонкий шрифт»; «не должен наслаиваться на другие папки»; «выделением, ванильным
виндовсовским, выделять папки и одновременно перетаскивать»; «чтобы ощущалось как нативная функция Windows»;
«понятный интерфейс у самого приложения, ярлык для запуска, воркшоп с модификациями — виджеты включить/выключить»;
«в стиле плиток, прозрачное, прям охуенно, как шоурил, но нагрузка минимальная»; «у каждого виджета возможность
растягивать, и он масштабируется; включить/выключить привязку к сетке».

Решения владельца (опрос 06.11.2026):
- Виджеты: музыка, корзина, часы и дата, нагрузка ПК, погода, заметка. Каждый включается в мастерской.
- Каждый виджет двигается и растягивается за края, содержимое масштабируется; привязка к сетке — у каждого своя.
- Выделение: рамкой Windows по столу и Ctrl+клик; тянешь любую выделенную — едут все.
- Наезд: отпустили поверх другой — соседи расступаются в ближайшее свободное место.
- Окно приложения: Мастерская виджетов, Папки, Внешний вид, Нагрузка программы (с экономным режимом).
- Ярлык «Плитки» в Пуске и на столе; повторный запуск открывает окно приложения.

Критерии приёмки:
- Расступание: A(0,0,2×2) отпустили на B(0,0) → B уезжает в ближайшую свободную клетку, A на месте, никто не пересекается,
  все внутри рабочей области.
- Группа: сдвиг двух выделенных на (+1 клетку) двигает обе; у края группа упирается целиком, форма не ломается.
- Рамка: выделены те, чей прямоугольник пересекает рамку.
- Растягивание виджета: с сохранением пропорций, масштаб от 0.6 до 3 от базового; с привязкой шаг — клетка.
- Обложка трека появляется, даже если плеер присылает её позже названия.
- Экономный режим: стекло не обновляется по таймеру, нагрузка ПК раз в 5 с, погода раз в час.
- В простое (ничего не играет, мышь не двигается) программа тратит меньше 1% одного ядра.
