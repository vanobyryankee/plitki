# 03. Языки «Плиток»

Просьба владельца 06.11.2026: «добавь поддержку всех популярных мировых языков в приложение и виджетам».

## Решения владельца из опроса (дословно)

- Языки: «10 главных»: русский, английский, китайский (упрощённый), испанский, португальский (Бразилия),
  французский, немецкий, японский, корейский, турецкий.
- Выбор: «Как в Windows + выбор»: сам берёт язык Windows, в окне приложения список, смена сразу без перезапуска.
- Арабский: «Зеркалить окна». В список 10 главных арабский не вошёл, письма справа налево нет; зеркалить нечего.
- Папки: «Только новые»: новые папки получают название на выбранном языке, уже созданные не трогаем.

## Как устроено

- `Tiles.Core/Loc.cs`: `Loc.T("русская строка", args…)`. Ключ — сама русская строка, перевод берётся из
  `lang/<код>.json` (встроены в программу), чего нет — показываем русскую. `Loc.Set(код)`, событие `Loc.Changed`.
  Коды: ru en zh es pt fr de ja ko tr. Пустой код = язык Windows; не из списка → английский.
- `Loc.Culture`: числа, даты, дни недели (скорость «10,5» / «10.5», погода по дням) по выбранному языку.
- Настройка `TilesConfig.Language` ("" = как в Windows).
- В окне приложения, на странице вида, список «Язык»: «Как в Windows» и 10 языков своими именами (English, Deutsch…).
- По `Loc.Changed`: виджеты перестраиваются, окно приложения перерисовывает страницы, подписи плиток и меню
  (меню строятся при открытии и так).
- Журнал (`tiles.log`) остаётся по-русски: это для меня, не для пользователя.

## Приёмка (вход → результат)

1. `Loc.T("Открыть пульт")` при en → «Open control panel»; при ru → как есть; ключа нет в en → русская строка.
2. Строка с местами `{0}`: перевод обязан содержать те же места (проверка по всем языкам).
3. Каждая строка `Loc.T("…")` в исходниках есть во всех 9 файлах переводов, без пустых значений (проверка сканирует код).
4. Язык Windows `de-DE`, настройка пустая → немецкий; `ar-SA` → английский.
5. Смена языка в окне приложения → виджеты и окно сразу на новом языке, без перезапуска; выбор сохраняется.
6. Снимки виджетов и окна приложения на en, zh, ja, de: ничего не обрезано и не вылезает (длинные немецкие слова).
7. Новая папка «Игры» при en называется «Games»; старые папки не переименованы.
